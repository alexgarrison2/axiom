# Trophy artwork: provenance

Every SVG in this folder is an original illustration, drawn in code by
`scripts/trophies/trophies.py` (house kit: `scripts/trophies/core.py`). No
photograph was traced, vectorised or embedded, so no third-party licence
attaches to the files. Photos were used only as visual reference for each
trophy's proportions and details.

Regenerate: `cd scripts/trophies && python3 trophies.py ../../public/trophies`
